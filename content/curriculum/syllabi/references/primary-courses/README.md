# Primary Course Syllabi

This directory contains current and historical reference syllabi for:

- Movement Systems (3-credit lecture)
- Exercise Prescription & Nutrition (3-credit lecture)

These documents describe the legacy course configuration. The redesigned lectures and
shared laboratory are developed separately under `syllabi/development/`. Historical
credit allocations in these references do not define the Spring 2027 model: Movement
Systems is 4 credits including the shared lab, and EP&N is 3 credits. The same cohort
takes both courses, and only those two courses have syllabi.

Third-party syllabi, future-adjunct submissions, correspondence, Canvas exports, and
other restricted source files belong in the external private teaching archive. This
repository retains only non-sensitive provenance and inventory records for those
collections. Preserve archived sources unchanged; adapt material deliberately in the
corresponding development directory after reviewing ownership and permission.
