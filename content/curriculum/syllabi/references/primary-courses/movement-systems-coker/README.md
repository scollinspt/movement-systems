# Movement Systems: Coker Reference Materials

The external private teaching archive preserves Movement Systems materials from Eydie
Coker's prior course offerings as historical curricular evidence. These files may inform
Sean Collins's redesigned Movement Systems course, but they are not authoritative sources
for the new course and should remain unchanged.

- The collection includes a reference syllabus.
- The Spring 2026 collection includes the original Canvas export, a non-destructive
  extraction, recovered case-colliding archive members, and any separately supplied files.

This repository retains only non-sensitive provenance and inventory records. The Canvas
record may include copyrighted readings, assessment content, instructor-owned materials,
external links, and files with student-related labels. It is private reference material
and must not enter the public website without item-level review and permission.
