# Exercise Prescription & Nutrition Reference Record

Historical syllabi and future-adjunct submissions for Exercise Prescription & Nutrition
are retained in the external private teaching archive. These sources include third-party
course materials and correspondence and are not part of the public repository.

The collection currently records a legacy Coker syllabus and a future-adjunct submission
from Connor containing a draft syllabus, correspondence, and supporting course-development
materials. Ownership and publication permission must be reviewed before adapting or
publishing any contributed material.

Authoritative redesigned curriculum belongs under the corresponding `development/`
directory. This file records provenance only and does not imply redistribution permission.
