# Exercise Prescription & Nutrition Syllabus

Build the operational 3-credit Exercise Prescription & Nutrition syllabus in the private
PTH6132 course workspace, not in this public repository. EP&N provides the primary
content basis for the shared Movement and Exercise Laboratory, so its private syllabus
must reference the laboratory and include the same lab schedule as the Movement Systems
syllabus.

When syllabus development begins, start from its own copied release of the separate
`syllabus-template` workspace. Keep the copied class, license, required assets, and a
`TEMPLATE_SOURCE.md` provenance record with the private course source. Do not share a
live template or a mutable course source with the Movement Systems syllabus.

The syllabus should position EP&N in Knowledge Foundations and identify its contribution
to shared concepts, laboratory work, and patient/client management. This repository does
not claim ownership of the future adjunct's PowerPoints; those instructor-owned artifacts
remain in private course storage or Canvas. Only permission-cleared, durable EP&N
resources should enter this repository or the public site.
