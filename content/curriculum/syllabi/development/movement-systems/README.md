# Movement Systems Syllabus

Build the operational 4-credit Movement Systems syllabus in the private PTH6132 course
workspace, not in this public repository. It includes the shared Movement and Exercise
Laboratory and its complete schedule.

When syllabus development begins, start from a copied release of the separate
`syllabus-template` workspace. Keep the copied class, license, required assets, and a
`TEMPLATE_SOURCE.md` provenance record with the private course source. Do not use the
historical PTH6111 snapshot in this repository as the active template.

The syllabus should position the course in the Systems Theory sequence and align its
outcomes with shared concepts, laboratory applications, and PCM III-V transfer.
The laboratory content is based primarily on EP&N and must remain synchronized privately
with the schedule and references in the EP&N syllabus. Project-authored concepts or
educational resources may be promoted into this repository when they have durable value
beyond one course offering and pass the review described in
[../../../../../docs/publication-policy.md](../../../../../docs/publication-policy.md).
