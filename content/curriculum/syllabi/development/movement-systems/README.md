# Movement Systems Syllabus

Build the new Movement Systems lecture syllabus here. Keep its LaTeX entry point at
`syllabus.tex`; place extracted sections and course-specific assets in the corresponding
subdirectories when they are needed.

The syllabus should position the course in the Systems Theory sequence and align its
outcomes with shared concepts, laboratory applications, and PCM III-V transfer.
Movement Systems presentations intended for the public site remain project-authored
course content, but their publication requires the review described in
[../../../../../docs/publication-policy.md](../../../../../docs/publication-policy.md).
