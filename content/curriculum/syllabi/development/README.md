# Syllabus Development

This directory contains the LaTeX sources for the redesigned Movement Systems and
Exercise Prescription & Nutrition lectures and their shared laboratory.

- `shared/` is for the reusable syllabus style, a representative source example, and
  assets common to more than one syllabus.
- Each course directory owns its syllabus source, course-specific sections, and assets.

The syllabi define course commitments and coordination, but do not require all teaching
artifacts to be stored here. In particular, adjunct-owned EP&N PowerPoints may remain in
Canvas. Generated PDFs should not replace the source files as the authoritative
versions, and no syllabus is public merely because its source is in this directory. See
[../../../../docs/publication-policy.md](../../../../docs/publication-policy.md).

The final deliverables of roadmap Phase 1 are complete Spring 2027 LaTeX syllabi for
Movement Systems and EP&N. Use
`shared/example/PTH6111_Syllabus/template.tex` as their structural and visual starting
point. The shared-laboratory syllabus and cross-component schedule refinement continue
in Phase 2.
