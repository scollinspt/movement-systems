# Syllabus Development

This directory contains the LaTeX sources for the redesigned Movement Systems and
Exercise Prescription & Nutrition lectures and their shared laboratory.

- `shared/` is for the reusable syllabus style, a representative source example, and
  assets common to more than one syllabus.
- Each course directory owns its syllabus source, course-specific sections, and assets.

Generated PDFs should not replace the source files as the authoritative versions.
