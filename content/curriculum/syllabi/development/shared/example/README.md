# Syllabus Example

This directory is the retained PTH6111 source snapshot that seeded the separate
`syllabus-template` workspace. Its current `template.tex` and `inzane_syllabus.cls` were
byte-identical to that workspace baseline when the relationship was documented on
2026-09-25.

Do not develop new syllabi from this public snapshot. Genericization and releases belong
in `syllabus-template`; operational course development uses copied, versioned releases in
the private course workspace. Preserve the included license and attribution.
