# Project Documentation

This directory contains decisions that apply across curriculum, website, laboratory,
and research work.

- [research-architecture.md](research-architecture.md): scientific position, HMS Lab
  role, research lifecycle, repository authority, and public communication rules.
- [content-model.md](content-model.md): reusable records for theories, questions,
  methods, capabilities, projects, results, models, and educational resources.
- [curriculum-architecture.md](curriculum-architecture.md): relationship among Systems
  Theory, Knowledge Foundations, shared concepts, laboratory work, and practice.
- [clinical-inquiry-integration.md](clinical-inquiry-integration.md): movement-domain
  contributions to Models4PT, the Clinical Inference Engine, and the wider Clinical
  Inquiry Ecosystem.
- [site-plan.md](site-plan.md): public website audience, navigation, and publishing model.
- [publication-policy.md](publication-policy.md): ownership, privacy, permissions, and
  public/private and research-governance boundaries.
- [workspace-integration.md](workspace-integration.md): responsibilities and transfer
  points among repositories in the workspace.

The phased implementation sequence is maintained in [../ROADMAP.md](../ROADMAP.md).
